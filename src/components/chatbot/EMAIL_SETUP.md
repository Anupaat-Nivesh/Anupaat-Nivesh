# Email Service Setup Guide

This guide explains how to set up email functionality for the chatbot's lead generation form.

## Overview

When a user submits their contact information (email or phone), the system will:
1. **Send a confirmation email to the user** (if email provided)
2. **Send a notification email to ops team** (`ops.anupaatnivesh@gmail.com`)

## Setup Options

### Option 1: EmailJS (Recommended for Quick Setup)

EmailJS allows sending emails directly from the frontend without a backend server.

#### Step 1: Sign up for EmailJS
1. Go to https://www.emailjs.com/
2. Sign up for a free account (200 emails/month free)
3. Verify your email address

#### Step 2: Connect Gmail Service
1. In EmailJS dashboard, go to **Email Services**
2. Click **Add New Service**
3. Select **Gmail**
4. Connect your Gmail account (`anupaatnivesh@gmail.com`)
5. Note down the **Service ID** (e.g., `service_xxxxx`)

#### Step 3: Create Email Templates

**Template 1: User Confirmation Email**
1. Go to **Email Templates** → **Create New Template**
2. Template Name: `user_confirmation`
3. Subject: `Thank you for contacting Anupaat Nivesh`
4. Content:
```
Hello {{to_name}}! 👋

Thank you for contacting Anupaat Nivesh.

What happens next:
✓ Our expert advisors will connect with you shortly
✓ We'll discuss a personalized investment plan
✓ We'll suggest the best strategy based on your goals

Next Steps:
Our team will call or email you within 24-48 hours.

If you have any urgent questions, you can contact us directly:
📧 contact@anupaatnivesh.com
📱 9501195200

Thank you for your interest! 🙏

Anupaat Nivesh Team
```
5. Note down the **Template ID** (e.g., `template_xxxxx`)

**Template 2: Ops Notification Email**
1. Create another template: `ops_notification`
2. Subject: `New Lead: {{intent}} - {{lead_name}}`
3. Content:
```
🔔 New Lead from Chatbot

Contact Information:
• Name: {{lead_name}}
• Email: {{lead_email}}
• Phone: {{lead_phone}}

Lead Details:
• Intent: {{intent}}
• Language: {{language}}
• Conversation Length: {{messages_count}} messages
• Timestamp: {{timestamp}}

Conversation Summary:
{{conversation_summary}}

Action Required:
Please contact this lead within 24-48 hours.

---
Generated by Anupaat Nivesh Chatbot
```
4. Note down the **Template ID**

#### Step 4: Get Public Key
1. Go to **Account** → **General**
2. Copy your **Public Key** (e.g., `xxxxxxxxxxxxx`)

#### Step 5: Configure Environment Variables
Create a `.env` file in the project root (or add to existing `.env`):

```env
REACT_APP_EMAILJS_SERVICE_ID=service_xxxxx
REACT_APP_EMAILJS_TEMPLATE_ID=template_xxxxx
REACT_APP_EMAILJS_PUBLIC_KEY=xxxxxxxxxxxxx
REACT_APP_EMAILJS_ENABLED=true
```

**Note:** You can use the same template ID for both emails, or create separate templates. The code will work with either approach.

#### Step 6: Restart Development Server
```bash
npm start
```

### Option 2: Backend API (Production)

For production, you can set up a backend API endpoint to send emails securely.

#### Step 1: Create Backend Endpoint
Create an API endpoint (e.g., `/api/send-email`) that:
- Accepts POST requests with contact data
- Sends emails using your email service (Gmail API, SendGrid, etc.)
- Returns success/error response

#### Step 2: Configure Environment Variables
```env
REACT_APP_EMAIL_API_ENDPOINT=https://your-api.com/api/send-email
REACT_APP_EMAIL_API_ENABLED=true
```

## Testing

1. Fill out the contact form in the chatbot
2. Submit with a valid email
3. Check:
   - User receives confirmation email
   - `ops.anupaatnivesh@gmail.com` receives notification email
4. Check browser console for email sending logs

## Troubleshooting

### Emails not sending
- Check browser console for errors
- Verify environment variables are set correctly
- Ensure EmailJS service is connected to Gmail
- Check EmailJS dashboard for email logs

### "EmailJS library not available"
- Run: `npm install @emailjs/browser`
- Restart development server

### "Email service not configured"
- Set `REACT_APP_EMAILJS_ENABLED=true` in `.env`
- Or set `REACT_APP_EMAIL_API_ENABLED=true` for backend API

## Notes

- Email sending is **non-blocking** - form submission will succeed even if email fails
- Email failures are logged but don't prevent lead from being saved
- For production, consider using a dedicated email service (SendGrid, AWS SES, etc.)
