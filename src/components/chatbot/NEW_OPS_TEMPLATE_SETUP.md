# Setup Guide: New EmailJS Template for Ops Lead Notifications

## Step 1: Create New Template in EmailJS

1. Go to [EmailJS Dashboard](https://dashboard.emailjs.com/)
2. Navigate to **Email Templates**
3. Click **"Create New Template"** or **"Add New Template"**
4. Name it: `Ops Lead Notification` or `ArthAI Sales Lead`

## Step 2: Configure Template Settings

### Basic Settings:
- **Template Name**: `Ops Lead Notification`
- **Service**: Select `service_f3brm8k` (your existing service)
- **To Email**: `ops.anupaatnivesh@gmail.com` ⚠️ **CRITICAL: Set this to ops email**
- **From Name**: `ArthAI - Anupaat Nivesh`
- **From Email**: `anupaatnivesh@gmail.com` (or your configured sender)
- **Reply To**: `anupaatnivesh@gmail.com`

### Subject Line:
```
New Sales Lead from ArthAI - {{intent}}
```

## Step 4: Template Variables Mapping

The template uses these variables (already mapped in code):

| Template Variable | What It Contains | Example |
|------------------|------------------|---------|
| `{{first_name}}` | Email with emoji prefix | `📧 user@example.com` |
| `{{last_name}}` | Phone with emoji prefix | `📱 9544456788` |
| `{{user_email}}` | Lead's email address | `user@example.com` |
| `{{number}}` | Lead's phone number | `9544456788` |
| `{{lead_name}}` | Lead's name (if provided) | `John Doe` |
| `{{lead_email}}` | Lead's email (duplicate) | `user@example.com` |
| `{{lead_phone}}` | Lead's phone (duplicate) | `9544456788` |
| `{{intent}}` | User's intent/interest | `wealth_creation` |
| `{{language}}` | Conversation language | `English` or `Hindi` |
| `{{messages_count}}` | Number of messages | `5` |
| `{{conversation_summary}}` | Brief conversation summary | `User asked about SIP...` |
| `{{message}}` | Full structured lead data | Complete formatted text |
| `{{subject}}` | Email subject | `New Sales Lead from ArthAI` |

## Step 5: Get Template ID

1. After creating and saving the template
2. Copy the **Template ID** (it will look like `template_xxxxxxx`)
3. You'll need this in the next step

## Step 6: Update Code Configuration

Once you have the new template ID, update `src/components/contact/Config.js`:

```javascript
export const emailJSOpsTemplateID = "template_xxxxxxx"; // Your new template ID here
```

Then the code will automatically use this new template.

## Step 8: Verify in Production

1. Submit a contact form in the chatbot
2. Check console logs for: `✅ Ops lead notification email sent via EmailJS`
3. Check `ops.anupaatnivesh@gmail.com` inbox (and spam folder)
4. Verify all lead data is visible and formatted correctly

## Troubleshooting

- **Email not received**: Check spam folder, verify "To Email" is set correctly
- **Missing data**: Verify all template variables are included in template content
- **Wrong recipient**: Double-check "To Email" field in template settings
- **Template not found**: Verify template ID is correct in `Config.js`

## Notes

- The template will automatically receive all the data we're sending
- `first_name` and `last_name` contain email and phone with emojis for visibility
- `message` contains the full structured lead data
- All fields are optional, so missing data won't break the template
