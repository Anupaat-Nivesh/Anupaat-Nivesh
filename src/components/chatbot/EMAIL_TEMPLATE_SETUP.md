# Email Template Setup for Ops Lead Notifications

## Issue
The current EmailJS template (`template_agep8yl`) is designed for user confirmation emails and uses a fixed message. It doesn't display the lead data (email, phone) properly for the ops team.

## Solution
You have two options:

### Option 1: Create a New EmailJS Template for Ops (Recommended)

1. Go to EmailJS Dashboard → Email Templates
2. Click "Create New Template"
3. Name it: `ops_lead_notification` or similar
4. Set up the template with these fields:

**Template Content:**
```
Subject: 🔔 NEW SALES LEAD: {{intent}} - {{lead_name}}

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
NEW SALES LEAD FROM CHATBOT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

👤 CONTACT DETAILS:
📧 Email: {{user_email}}
📱 Phone: {{number}}
👤 Name: {{first_name}} {{last_name}}

🎯 LEAD QUALIFICATION:
🎯 Intent: {{intent}}
🌐 Language: {{language}}
💬 Conversation Length: {{messages_count}} messages

📝 CONVERSATION SUMMARY:
{{conversation_summary}}

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
FULL LEAD DATA:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
{{message}}

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Generated by Anupaat Nivesh Chatbot
```

5. Note down the new Template ID
6. Update `src/components/contact/Config.js`:
   ```javascript
   export const emailJSOpsTemplateID = "template_xxxxx"; // Your new template ID
   ```
7. Update `src/components/chatbot/emailService.js` to use this template:
   ```javascript
   opsTemplateId: emailJSOpsTemplateID || emailJSMFtemplteID || emailJStemplateID
   ```

### Option 2: Modify Existing Template

1. Go to EmailJS Dashboard → Email Templates
2. Edit `template_agep8yl` (or create a copy)
3. Update the template to use the `{{message}}` field which contains the structured lead data
4. Make sure the template displays:
   - `{{user_email}}` - Lead's email
   - `{{number}}` - Lead's phone
   - `{{message}}` - Full lead data

## Current Workaround

Until you create a new template, the code now puts:
- Email in `first_name` field (prefixed with 📧)
- Phone in `last_name` field (prefixed with 📱)
- Full lead data in `message` field

This ensures the email and phone are visible even if the template doesn't use the `message` field properly.

## Testing

After updating the template:
1. Submit a contact form in the chatbot
2. Check `ops.anupaatnivesh@gmail.com`
3. Verify you see:
   - Lead's email address
   - Lead's phone number
   - Full lead data with conversation summary
